# Jaiprakash - YouTube AI Studio

A lightweight web app for YouTube creators to generate AI-powered content plans, scripts, title ideas, thumbnail concepts, and engagement strategies.

## Features
- OpenAI-compatible API integration (base URL, model, API key)
- Viral video idea generation
- High-CTR title generation
- Full script drafting
- Thumbnail concept + prompt generation
- Hook + chapters plan
- Community engagement strategy generation
- Theme toggle (dark/light)

## Run locally
```bash
python3 -m http.server 4173
```
Then open: `http://localhost:4173`

## Notes
- API credentials are stored in your browser's local storage.
- Works with OpenAI-compatible chat completions endpoints.
